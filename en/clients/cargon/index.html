CargOn: data warehouse and 4 predictive dashboards in 30 days

CargOn turned the data generated inside its platform into a new product for its customers: a data warehouse, ETL pipelines and Power BI logistics dashboards with forecasts, so operations stop looking backward and start anticipating.

The case in questions

How the project went.

Website of CargOn →

Who is CargOn?

CargOn is a logistics platform, and its customers generate operational data inside it. It is an Agência Byte client.

What was the goal of the project?

To create one more product, to monetize its customer base, from the data the platform itself generates. For that, the data had to be organized into a single, reliable base ready for analysis.

What did Agência Byte do?

It created a data warehouse, built the ETL that moves the platform's data into it and delivered a logistics dashboard in Power BI for all customers. The dashboards include forecasts, so logistics can see what is coming instead of analyzing history only.

What were the numbers?

4 dashboards for CargOn's customers, built in 30 days.

What changed for logistics?

Analysis stopped being just a rear-view mirror. With organized data and forecasts, CargOn's customers' operations become predictive and CargOn gains a data product to offer.

How long did it take?

30 days, from organizing the data to having the dashboards live.

Which technologies were used?

A database with the data generated in the platform, a data warehouse and ETL hosted on Azure, and Power BI dashboards.
